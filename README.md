# মুক্তগ্রন্থ (MuktoGrontho) - বাংলা ই-বুক প্ল্যাটফর্ম

উন্মুক্ত বাংলা ইবুক সংগ্রহ, বই পর্যালোচনা এবং লেখক তথ্যের সম্পূর্ণ প্ল্যাটফর্ম।

## 🌟 বৈশিষ্ট্যসমূহ

### ✅ সম্পন্ন বৈশিষ্ট্য

#### 🏠 মূল পাতা (index.html)
- **রেসপন্সিভ ডিজাইন**: সকল ডিভাইসে অপটিমাইজড
- **ইন্টারঅ্যাক্টিভ নেভিগেশন**: স্মুথ স্ক্রলিং এবং সেকশন সুইচিং
- **উন্নত বই সার্চ**: রিয়েল-টাইম ফিল্টারিং এবং সর্টিং
- **ডেটা ভিজুয়ালাইজেশন**: Chart.js দিয়ে ইন্টারঅ্যাক্টিভ চার্ট
- **অ্যাকর্ডিয়ন সেকশন**: প্রকল্পের তথ্যের জন্য কলাপসিবল UI

#### 📖 বইয়ের পাতা (book.html)
- **ডায়নামিক বুক ডিটেইল**: URL প্যারামিটার থেকে বই লোড
- **রিভিউ সিস্টেম**: localStorage ব্যবহার করে রিভিউ সংরক্ষণ
- **রেটিং সিস্টেম**: ৫-স্টার রেটিং ফিচার
- **সোশ্যাল শেয়ারিং**: Facebook, Twitter, WhatsApp শেয়ার বাটন
- **রেসপন্সিভ লেআউট**: মোবাইল-বান্ধব ডিজাইন

#### 👤 লেখকের পাতা (author.html)
- **ডায়নামিক অথর প্রোফাইল**: URL প্যারামিটার থেকে লেখক লোড
- **বই ফিল্টারিং**: জেনার এবং সার্চ দিয়ে বই খুঁজুন
- **পরিসংখ্যান ড্যাশবোর্ড**: লেখকের বই সংখ্যা, জেনার ইত্যাদি
- **বাহ্যিক লিংক**: Goodreads এবং Wikipedia সংযোগ
- **উন্নত UI**: গ্রিড লেআউট এবং হোভার ইফেক্ট

#### 📝 ব্লগ পাতা (blog.html)
- **স্ট্যাটিক কন্টেন্ট**: প্রকল্প সংবাদ এবং আপডেট
- **কার্ড-ভিত্তিক লেআউট**: আকর্ষণীয় ব্লগ পোস্ট প্রদর্শন
- **রেসপন্সিভ ডিজাইন**: সকল ডিভাইসে সুন্দর প্রদর্শন

### 🏗️ আর্কিটেকচার ও কোড কোয়ালিটি

#### 🔧 শেয়ার্ড কম্পোনেন্ট সিস্টেম
- **assets/js/shared.js**: কেন্দ্রীভূত জাভাস্ক্রিপ্ট লাইব্রেরি
  - গ্লোবাল নেমস্পেস (`MuktoGrontho`)
  - রি-ইউজেবল UI কম্পোনেন্ট (হেডার, ফুটার, ব্রেডক্রাম্ব)
  - API সার্ভিস এবং ইউটিলিটি ফাংশন
  - স্ট্যান্ডার্ড ইভেন্ট হ্যান্ডলিং

- **assets/css/shared.css**: কেন্দ্রীভূত স্টাইলশিট
  - CSS কাস্টম প্রপার্টি (ভেরিয়েবল)
  - রেসপন্সিভ ডিজাইন প্যাটার্ন
  - অ্যাক্সেসিবিলিটি ফিচার
  - ক্রস-ব্রাউজার সাপোর্ট

#### 🛠️ টেকনিক্যাল স্ট্যাক

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **CSS Framework**: Tailwind CSS + কাস্টম CSS
- **চার্টিং**: Chart.js
- **ফন্ট**: Hind Siliguri (Google Fonts)
- **হোস্টিং**: GitHub Pages
- **ডেটা স্টোরেজ**: JSON ফাইল + localStorage

#### � বাগ ফিক্স
- **টেবিল সর্টিং বাগ**: ↕️ আইকন accumulation সমস্যা সমাধান
- **শেয়ার্ড কম্পোনেন্ট**: কোড ডুপ্লিকেশন দূরীকরণ
- **রেসপন্সিভ ইস্যু**: ফুটার জাম্পিং সমস্যা সমাধান
- **প্লেসহোল্ডার ইমেজ**: অনুপস্থিত ইমেজের জন্য CSS ভিত্তিক প্লেসহোল্ডার

## 🔧 ডেভেলপমেন্ট

### লোকাল সেটআপ
```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/MuktoGrontho/MuktoGrontho.github.io.git

# ডিরেক্টরি পরিবর্তন করুন
cd MuktoGrontho.github.io

# লোকাল সার্ভার চালু করুন
python -m http.server 8000

# ব্রাউজারে খুলুন
# http://localhost:8000
```
